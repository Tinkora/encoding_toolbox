# Support

- Read the [English documentation](./README.md) or [中文文档](./README.zh-CN.md).
- Ask usage questions in [GitHub Discussions](https://github.com/Tinkora/encoding_toolbox/discussions).
- Report reproducible bugs through [GitHub Issues](https://github.com/Tinkora/encoding_toolbox/issues).
- Request features by describing the real workflow, current workaround, and expected outcome.
- Report suspected vulnerabilities privately as described in [SECURITY.md](./SECURITY.md).

Please include the release version or commit, operating system, command or browser,
minimal input that reproduces the problem, expected result, and actual result. Remove
secrets and personal data before posting public logs or examples.
